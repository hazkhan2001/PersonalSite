This is a template for an economic analysis. It is marked `draft: true`, so it stays hidden.

Tables work in Markdown too, which is handy for figures:

| Quarter | GDP growth | Inflation |
|---------|-----------:|----------:|
| Q1      |       2.1% |      3.4% |
| Q2      |       1.8% |      3.1% |

Footnotes work like this.[^1]

[^1]: The footnote text goes at the bottom.

To include a chart, save it as an image in `static/images/` and add `![Description of the chart](/static/images/my-chart.png)`.
