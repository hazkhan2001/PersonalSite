Put your own manuscript photographs in this folder.

Then, in content/data/manuscripts.yaml, point to them like this:

  images:
    - src: "manuscripts/topkapi-quran-leaf.jpg"
      caption: "Opening page, photographed at the museum"

and set   source: own-photo

Tips:
- Use lowercase file names with hyphens, no spaces.
- Resize large phone photos to about 1600 pixels wide before adding them,
  so pages load quickly. GitHub also limits files to 100 MB.
- Check the museum or library's photography policy before publishing.
